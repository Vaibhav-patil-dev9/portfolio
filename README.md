## 📂 Installation

Clone Repository

```bash
git clone https://github.com/Vaibhav-patil-dev9/portfolio.git
```

Move into folder

```bash
cd portfolio
```

Install dependencies

```bash
npm install
```

Run project

```bash
npm run dev
```
